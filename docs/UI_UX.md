# UI_UX.md

## Moments ❤️

---

# 1. DESIGN PHILOSOPHY

Moments is designed around:

> “Soft utility, emotional clarity, and invisible complexity.”

The UI must feel:

* calm, not noisy
* intimate, not social
* intentional, not addictive
* expressive, not cluttered

No AI-looking gradients, no flashy neon systems, no gimmicky visuals.

---

# 2. CORE UX PRINCIPLES

---

## 2.1 Emotional First Design

Every screen answers:

> “How does my partner feel right now?”

Not:

* engagement metrics
* feeds
* trends

---

## 2.2 Gesture Over Buttons

Interactions must feel natural:

* swipe
* long press
* drag
* double tap
* hold to reveal

Buttons are secondary.

---

## 2.3 One-Hand Usage Priority

All core actions must be reachable:

* bottom half of screen
* thumb zones
* minimal top interactions

---

## 2.4 No Cognitive Overload

Only 1 primary action per screen.

---

# 5. HOME UI / UX

---

## Layout Structure

* Top: Mood snapshot (you + partner)
* Middle: Latest Moment
* Below: Daily Question
* Bottom: Smart suggestions

---

## Interaction Design

* Tap moment → full view

---

## Emotional Behavior

> “checking on us”

not a dashboard.

# 6. MOMENTS UI

---

* soft spacing
* chronological timeline

---

## Gestures

* tap → create

# 7. CHAT UI

---

## Layout

* bubble-based messaging
* soft alignment (left/right)
* minimal timestamps

---

## Gestures

* swipe on message → reply
* long press → reactions
* drag message → pin

---

## Special Behavior

* typing indicator is subtle (no animation overload)
* read receipts optional toggle

---

## Voice Messages

* hold to record
* release to send
* swipe left to cancel

# 12. THEME SYSTEM

---

## 12.1 Design Goal

Themes should feel:

* emotional
* subtle
* personal
* non-distracting
* you can include the current template design and color schemes.

NOT:

* neon
* cyberpunk
* AI glow effects
* gradients overload

---

## 12.2 Available Themes

---

### 1. Soft Ivory (Default)

* white background
* warm neutrals
* soft shadows

---

### 2. Midnight Calm

* dark slate background
* muted text
* low contrast accents

---

### 3. Warm Sand

* beige tones
* earthy palette
* cozy aesthetic

---

### 4. Ocean Glass

* soft blue accents
* minimal contrast
* calming feel

---

### 5. Rose Memory

* soft pink accents
* romantic tone
* gentle highlights

---

## 12.3 Theme Rules

* no neon colors
* no animated gradients
* no aggressive contrast
* accessibility-first

---

# 13. MOTION DESIGN

---

## Rules

Motion must feel:

* slow
* natural
* soft
* non-distracting

---

## Animations

* fade in/out (default)
* slight vertical lift on cards
* soft scale on tap

---

## Avoid

* bouncing animations
* spinning loaders
* flashy transitions

---

# 14. GESTURE SYSTEM (CORE)

---

## Global Gestures

| Gesture     | Action         |
| ----------- | -------------- |
| Tap         | Open           |
| Double Tap  | Like / React   |
| Long Press  | Options        |
| Swipe Left  | Dismiss        |
| Swipe Right | Save           |
| Swipe Down  | Refresh / Exit |
| Hold        | Quick action   |

---

# 15. FEELING OF THE APP

Moments should feel like:

> “A private emotional space for two people living life together.”

Not:

* social media
* chat app
* productivity tool

---

# 16. ACCESSIBILITY RULES

* large touch targets
* readable contrast
* no reliance on color alone
* haptic feedback optional

---

# 17. PERFORMANCE UX RULES

* instant tab switching (<100ms perceived)
* skeleton loaders for feeds
* offline cached chat
* optimistic UI updates

---

# 18. CORE UI RULE

> If a UI element distracts from emotional connection, it should be removed.
