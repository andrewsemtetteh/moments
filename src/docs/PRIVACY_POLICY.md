# PRIVACY_POLICY.md

## Moments ❤️

---

# 1. OVERVIEW

Moments is a private relationship application designed for two people to share experiences, emotions, and memories.

We prioritize:

> privacy, emotional safety, and data minimization

---

# 2. DATA WE COLLECT

We only collect data necessary for core functionality.

## 2.1 Account Data

* email address
* display name
* profile image (optional)

---

## 2.2 Relationship Data

* relationship pairing (user 1 + user 2)
* relationship metadata (name, status, streaks)

---

## 2.3 User-Generated Content

* messages
* moments (photos, videos, text)
* journal entries
* mood logs
* calendar events
* activity data

---

## 2.4 Technical Data

* device type
* app usage analytics (aggregated)
* crash reports

---

# 3. HOW WE USE DATA

We use data to:

* enable communication between partners
* store shared memories
* generate activities and suggestions
* maintain streaks and relationship features
* improve app performance and stability

We do NOT use data for:

* selling ads
* third-party profiling
* external marketing networks

---

# 4. DATA SHARING

We do NOT sell user data.

Data is only shared:

* between the two users in a relationship
* with service providers (for functionality only)

---

## Service Providers

* Supabase (database, auth, storage)
* RevenueCat (subscriptions)
* PostHog (analytics)
* Sentry (error tracking)
* Anthropic (AI features via Claude API)
* Expo (notifications)
* Resend (email services)

---

# 5. DATA STORAGE & SECURITY

* All data is encrypted in transit (HTTPS)
* Sensitive media is stored securely with signed URLs
* Access is strictly controlled via relationship-based permissions

---

# 6. DATA RETENTION

* Active data is stored while account is active
* Deleted accounts remove all associated relationship data
* Some anonymized analytics may be retained for system improvement

---

# 7. USER RIGHTS

Users can:

* access their data
* export their data
* delete their account and all associated data
* leave a relationship at any time

---

# 8. RELATIONSHIP PRIVACY MODEL

Moments is built on a strict model:

> Only two people can access a relationship space.

There are:

* no public profiles
* no discovery feeds
* no external visibility

---

# 9. CHILD SAFETY

Moments is not intended for users under 13.

We do not knowingly collect data from minors.

---

# 10. COOKIES & TRACKING

We do not use advertising cookies.

We only use:

* session cookies (authentication)
* analytics events (product improvement only)

---

# 11. AI USAGE

AI features are powered by:

Anthropic

AI is used only to:

* suggest activities
* generate prompts
* summarize memories

AI does NOT:

* make decisions for users
* store personal data independently
* access data outside relationship scope

---

# 12. CHANGES TO POLICY

We may update this policy occasionally.

Users will be notified of significant changes.

---

# 13. CONTACT

For privacy concerns:

* support channel (to be defined in app)
* or email support system (implementation dependent)

---

# 14. CORE PRIVACY PRINCIPLE

> Your relationship is private by design, not by promise.

---
